# 食品安全与特种设备监管应知应会测试卷 · 在线答题

一份**单文件、零依赖**的在线答题页面。含 100 道题（单选 70、判断 15、多选 15），满分 100 分。

## 使用方法

**下载 `index.html`，双击打开即可**，无需联网、无需安装任何东西。

也可以直接在线访问（如果开启了 GitHub Pages）：
`https://<你的用户名>.github.io/<仓库名>/`

## 功能

### 两种答题模式（可随时切换）

| | 练习模式（默认） | 考试模式 |
|---|---|---|
| 判分时机 | 答一题判一题，立即显示对错 | 全部答完后点「提交试卷」统一判分 |
| 作答后 | 锁定，显示正确答案 | 可随时改答案 |
| 顶部统计 | 已判分 / 正确 / 错误 / 得分 | 已答 / 未答 |
| 结果标题 | 练习结果 | 考试成绩 |

### 其他特性

- **选项乱序**：可开关。开启后每次进入页面随机打乱选项顺序，正确答案位置随之变化（按选项**文本**判题，不依赖字母位置），避免死记答案位置
- **成绩统计**：总分、答对/答错/未作答题数、正确率，以及**分题型得分**（单选 x/70、判断 x/15、多选 x/15）
- **错题回顾**：交卷后列出全部错题与未作答题，点击任意一条可跳回原题并高亮闪烁
- **「下一个未答」**：100 题一键跳转，避免翻找
- **重新开始**：清空作答记录重来
- **移动端适配**：手机浏览器可正常使用

## 题型说明

- **单选题（70 题）**：点击选项即完成作答，不可多选
- **判断题（15 题）**：正确 / 错误 两个选项
- **多选题（15 题）**：
  - 练习模式：勾选后需点「**确认答案**」才判分，勾选过程中不剧透
  - 考试模式：勾选即算已答，交卷时统一判分
  - 右上角显示「已选 N 项」，避免漏选

## 内容范围

- **网络餐饮 / 外卖**（约 35 题）：外卖封签、明厨亮灶摄像头、健康证公示、三防设施、消毒记录、平台公示信息等
- **副食品店**（约 51 题）：天花板/墙壁/地面/门窗/仓库要求、离墙离地存放、散装食品标签、保健食品专柜与警示语、临保食品专区、明码标价等
- **特种设备**（10 题，占 10%）：使用登记时限、定期检验申请、应急演练、作业人员证复审、气瓶充装记录、锅炉水位表冲洗

## 数据来源

题目与参考答案来自《食品安全与特种设备监管应知应会测试卷》原始文档（.doc 格式），经程序化解析提取并校验：

- 题量与分值校验通过（70+15+15 = 100 题 / 100 分）
- 题号连续，无缺号重号
- 100 个答案与题量一一对应，答案字母均在选项范围内

## 注意事项

- **答案内嵌在页面源码中**（按 F12 或查看源代码可获取）。本页面定位为**自测练习工具**，不适用于需要防作弊的正式考核场景。
- 特种设备部分个别题目依据的规章可能有版本更新（如气瓶充装记录保存期限），页面按原卷答案呈现，**正式考试请以最新法规及官方口径为准**。
